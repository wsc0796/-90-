## 五层模型 + 设备 + PDU

```
应用层 — 报文 Message — (无专属硬件)
运输层 — 段 Segment(TCP)/用户数据报(UDP) — (无专属硬件)
网络层 — 数据报 Datagram — 路由器(IP地址)
链路层 — 帧 Frame — 交换机(MAC地址48bit)
物理层 — 比特 Bit — 集线器/中继器(不看地址)
```

封装：报文→+TCP首部→段→+IP首部→数据报→+帧头尾→帧→+编码→比特

## 必背公式

```
发送时延 = L/R          传播时延 = d/v
奈氏 C = 2W·log₂(V)    香农 C = W·log₂(1+S/N)
dB→S/N: 10^(dB/10)     [10dB=10, 20dB=100, 30dB=1000, 40dB=10000]

Lmin = 2dR/v            Dmax = L·v/(2R)
比特率 = 波特率 × log₂(M)

主机位 h = 32-前缀      可用主机 = 2^h - 2
块大小 = 2^h            网络地址 = IP AND 掩码

GBN窗口 ≤ 2^n-1         SR窗口 ≤ 2^(n-1)
发送窗口 = min(rwnd, cwnd)
```

## 固定解题步骤速记

**CRC：** 多项式→二进制串→r→补r个0→模2除→r位余数→发送串=数据+余数

**子网：** h=32-前缀→块大小=2^h→网络地址(IP&掩码)→广播(主机位全1)→可用=网络+1到广播-1

**最长前缀：** 目的IP与每条路由掩码AND→收集匹配项→选/x最大者→下一跳

**IP分片：** MTU-20→调整到8倍数→片数=ceil(数据/每片)→偏移=累计/8→最后MF=0

**RIP：** 收到邻居路由每条距离+1→同跳替换/新跳取小更新→16不可达

**TCP序号：** SYN/FIN消耗1序号→ack=seq+数据长(非SYN/FIN段)

**拥塞控制：** 慢开始cwnd翻倍→达ssthresh转拥塞避免(+1/RTT)→超时:ssthresh=cwnd/2,cwnd=1→3重复ACK:快重传快恢复(ssthresh=cwnd/2,cwnd=ssthresh,拥塞避免)

## 判断题TOP10陷阱

1. ❌ 交换机隔离广播域 → 隔离冲突域，不隔离广播域
2. ❌ CRC可以纠错 → 只能检错
3. ❌ 集线器隔离冲突域 → 物理层，不隔离
4. ❌ ARP广播能穿越路由器 → 不能
5. ❌ 香农公式S/N可用dB代入 → 需换算为比值
6. ❌ CIDR前缀越短地址块越小 → 前缀越短块越大
7. ❌ TCP SYN不消耗序号 → SYN和FIN各消耗1个
8. ❌ 快重传收到2个重复ACK触发 → 3个
9. ❌ GBN接收方缓存乱序帧 → GBN丢弃，SR才缓存
10. ❌ IPv6路由器对过大数据报分片 → 不分片，丢弃+ICMPv6
