## 执行路线

### 今晚（3小时，目标：建立完整框架+掌握大题模板）

```
1. 打开 [03_今晚3小时执行稿](03_今晚3小时执行稿.md) → 严格按时间块执行
2. 配合阅读 [05_客观题速记册](05_客观题速记册.md) (只读第一部分易混概念对比)
3. 配合练习 [07_大题固定模板](07_大题固定模板.md) (做基础例题)
4. 闭卷做 [12_独立练习题](12_独立练习题.md) 中的题（不要打开08！）
5. 每块完成后闭卷默写，不合格即重来
```

### 明天上午（4小时，目标：大题全部独立完成+简答口述过关）

```
1. 打开 [04_明日上午做题训练](04_明日上午做题训练.md) → 严格按4小时段执行
2. 第1-3小时：闭卷做 [12_独立练习题](12_独立练习题.md) 中的大题（不要打开08！）
3. 补漏：做 [13_2025B卷高风险补漏](13_2025B卷高风险补漏.md) 中的题目
4. 第4小时：闭卷速写简答题，对照 [06_简答题背诵册](06_简答题背诵册.md) 自评
5. 所有错题标记并复做
```

### 明天下午（3小时，目标：完成完整训练卷+查漏补缺）

```
1. 闭卷做 [08_闭卷训练卷](08_闭卷训练卷.md) (100分钟)
2. 对照 [09_闭卷训练卷答案](09_闭卷训练卷答案.md) 逐题订正
3. 统计得分：选择__ 填空__ 判断__ 简答__ 大题__ = __/100
4. 错题标注类型：概念错/公式错/计算错/单位错/记忆错
5. 重做所有大题错题(直到做对)
```

### 明天晚上（2小时，目标：背诵+补弱）

```
1. 背诵 [06_简答题背诵册](06_简答题背诵册.md) → 口述全部18道简答题+5道名词解释
2. 快速刷 [05_客观题速记册](05_客观题速记册.md) 第三部分判断题50条陷阱
3. 重做 [07_大题固定模板](07_大题固定模板.md) 中今天错过的题型
```

### 考试当天上午（1.5小时，目标：保持手感+不学新内容）

```
1. 看 [10_考前一页纸](10_考前一页纸.md) → 全篇过一遍(15分钟)
2. 默写：五层+PDU+所有公式(10分钟)
3. 各做1题：CRC、子网划分、TCP拥塞控制(20分钟)
4. 口述6道简答题关键词链(15分钟)
5. 脑中过判断题TOP10陷阱(5分钟)
6. 闭眼休息，不再学新内容(15分钟)
```

## 状态检查清单

明天晚上睡觉前确认：

- [ ] 五层+PDU+设备能闭卷默写(一字不错)
- [ ] CRC步骤能闭卷默写
- [ ] 子网划分步骤能闭卷默写

## 放弃内容（不用纠结）

- 应用层全部(不考)
- CSMA/CA(知道是无线用即可)
- 二进制指数退避精确计算(记k=min(n,10)即可)
- PPP协议细节(记住"不可靠"即可)
- ADSL/HFC/FTTx接入技术
- 停止等待协议细节
